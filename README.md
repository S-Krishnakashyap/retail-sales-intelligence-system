
# Retail Sales Intelligence System

## Overview
A retail analytics case study using SQL and Python to examine sales performance, customer purchasing behaviour, regional revenue, and product profitability.

## Business Objectives
- Identify revenue and profit drivers across products and categories.
- Analyze monthly revenue trends and growth.
- Compare customer segments and spending behaviour.
- Evaluate regional sales performance.
- Understand repeat purchasing and customer loyalty.

## Tech Stack
- SQL (SQLite)
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Google Colab / Jupyter Notebook

## SQL Concepts Demonstrated
- JOINs and aggregate functions
- Common Table Expressions (CTEs)
- Subqueries and CASE expressions
- Window functions and ranking
- Date-based analysis
- Customer and profitability analysis

## Dataset
The notebook generates a relational dataset containing customers, products, and orders for the analysis. Confirm the final dataset size and whether the data is synthetic before publishing.

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells from top to bottom.
3. Review the SQL queries, analysis outputs, and visualizations.

## Project Structure
- `Retail_Sales_Intelligence_System_SQL.ipynb` — analysis, SQL queries, and visualizations.
